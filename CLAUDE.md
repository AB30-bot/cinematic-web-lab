# CLAUDE.md

## Home network

### Printer
- **Model:** Canon PIXMA TR4645 (shown as "TR4600 series" in the Canon PRINT app)
- **Type:** Inkjet all-in-one, black + color cartridges (PG-245 / CL-246 family)
- **Connection:** Wi-Fi; the user prints from their phone (Canon PRINT app)
- **Access:** Claude cannot reach it. It sits on the user's home network and
  sessions run in a cloud container. Claude can only advise; the user runs
  prints, maintenance and tests on the device.

### Printer notes
- Test with Setup > Maintenance > Print nozzle check pattern. A clean pattern
  means the printhead is fine; look at paper feed or print settings instead.
- Avoid cleaning/deep cleaning unless the nozzle check shows gaps (wastes ink).
- For tests, use Draft (brouillon) or Black & White, 1 copy.
- Paper jams: power off first, try the rear cover, pull slowly and straight.
  Do not open the casing (voids warranty).
- Ink levels are estimates from the Canon PRINT app.

### History
- 2026-10-06: First print came out striped and the paper jammed. After clearing
  the jam through the rear cover, the nozzle check was clean and ink was about
  85-90%. Cause was the paper feed, not the printhead.
